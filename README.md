# Structural-bioinformatics-and-elastic-network-analysis-
Structural bioinformatics and elastic network analysis 


This is the repository to store pipeline scripts, data, and computational result for this submitted manuscript

Callia Gracie GUNAWAN, Maria Lawrence Anabella LIAW, Dzaki EMIRSYAH, Christine SEPTIANI, Ivan OEY, Angelina SUHERLI, Arli Aditya PARIKESIT. 2026.
Structural bioinformatics and elastic network analysis of PALB2 missense variants in the BRCA2-binding domain. Ho Chi Minh City Open University Journal of Science - Engineering and Technology. [https://journalofscience.ou.edu.vn/index.php/tech-en/index](https://journalofscience.ou.edu.vn/index.php/tech-en/index).  (Manuscript submitted and under review)

Brief Explanation on the scripts and folders:
01_anm_palb2.py (site-perturbed ANM)
02_anm_figures.py (ANM figure generating)
data (raw data from genomic and proteomic repositories)
results (computational results)
